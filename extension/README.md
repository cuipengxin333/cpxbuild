# 百度截图搜索 Chrome 扩展

## 安装步骤

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载未打包的扩展程序」
4. 选择本项目的 `extension` 文件夹（注意：是在 `/Users/bytedance/Desktop/cpxbuild/extension`）
5. 扩展安装成功！

## 使用说明

1. 确保本地开发服务器正在运行（`npm run dev`）
2. 访问网站并进入「趣味生成」页面
3. 在输入框中输入要搜索的内容
4. 点击「📸 截图搜索」按钮
5. 等待几秒钟，搜索结果截图将显示在页面上
6. 可以点击「💾 下载图片」保存截图
